[폴더] app/ — 앱 최상단 위젯: 공용 Provider 등록 + MaterialApp.router 구성
════════════════════════════════════════════════════════════════

■ 이 폴더의 역할
   - 여러 화면(Route)이 함께 쓰는 객체를 MultiProvider로 앱 맨 위에 등록한다.
   - 테마·제목·라우터를 MaterialApp.router에 연결한다.

■ 넣지 않는 것
   - 화면별 ViewModel → router/app_router.dart의 각 Route에서 만든다.
   - .env 로드 같은 시작 준비 → main.dart

■ 파일 목록
   movie_log_app.dart   MovieLogApp — MultiProvider(TmdbMovieService) + MaterialApp.router   [사용 중]

■ 동작
   MultiProvider
    └ MaterialApp.router  ← 반드시 MultiProvider 안쪽에 있어야 한다
        └ GoRouter가 만드는 모든 화면에서 context.read<TmdbMovieService>() 가능
   Provider.create는 처음 read될 때 1번 실행 → Dio·Service 1개를 앱 전체가 공유

■ 의존 관계
   사용   : core/network/tmdb_client.dart, data/services/tmdb_movie_service.dart,
            router/app_router.dart, core/theme/app_theme.dart
   사용처 : main.dart

■ 수정할 때 주의
   - Provider를 MaterialApp.router 안쪽(특정 화면 아래)으로 옮기면
     다른 Route에서 ProviderNotFoundException이 난다.

■ 예정된 변경
   - 이후 주차: MovieLog 자체 API Client·인증 상태를 providers 목록에 추가
