[폴더] screens/ — 화면(View): 화면별 폴더 + 화면 전용 위젯
════════════════════════════════════════════════════════════════

■ 이 폴더의 역할
   - 상태를 읽어 화면을 그리고, 사용자 입력을 ViewModel에 전달한다.
   - 화면 하나 = 폴더 하나. 그 화면에서만 쓰는 위젯은 폴더 안의 widgets/에 둔다.
     (워크북은 screens/에 파일을 나란히 두지만, 3주차부터 화면별 폴더 컨벤션을 사용한다.
      "화면 코드와 데이터 코드를 섞지 않는다"는 원칙은 동일하다.)

■ 넣지 않는 것
   - API 호출·JSON 파싱·필터링 같은 비즈니스 로직 → view_models/, data/
   - 여러 화면이 함께 쓰는 위젯 → lib/widgets/

■ View 작성 규칙 (5주차)
   - 상태 구독 : Consumer<VM>(builder: ...) — 바뀌는 영역만 감싼다
                 홈: 인사 문구 아래만 / 영화 탭: body 전체(Chip 바 + 목록) / AppBar는 밖
   - 메서드 호출: 버튼·Chip 콜백 안에서 context.read<VM>().메서드()
   - 분기      : switch (viewModel.status) { idle||loading / error / empty / success }
   - 상세 이동 : context.push('/movies/${movie.id}', extra: movie) — index가 아니라 TMDB id

■ 상세 화면 데이터 규칙
   - URL의 movieId가 기준, extra(TmdbMovieDto)는 바로 그리기 위한 데이터
   - extra가 없거나(딥링크·재시작) id가 다르면 "영화 정보를 찾을 수 없어요" 안내
   - 평균 평점은 TMDB 10점(별 5개로 환산 + '8.5 / 10'), 내 평점은 5점('4.5 / 5')
   - 줄거리가 빈 문자열이면 "줄거리 정보가 없어요."

■ 의존 관계
   사용   : view_models/*, widgets/*, data/models/*(표시용 DTO 타입)
   사용처 : router/app_router.dart
