[폴더] data/ — Data Layer: 데이터를 가져오고(서버·기기) 변환한다
════════════════════════════════════════════════════════════════

■ 이 폴더의 역할
   - TMDB 응답 JSON을 DTO로 변환하고, API 요청 메서드를 제공한다.
   - 기기 저장소(shared_preferences) 읽기·쓰기를 담당한다.

■ 넣지 않는 것
   - "인기 5개", "최대 30개", "선택한 장르" 같은 화면 정책 → view_models/
   - 위젯·BuildContext·notifyListeners → UI Layer

■ 하위 폴더와 파일
   models/                               DTO: 응답 데이터 그릇
     tmdb_movie_dto.dart                 영화 1편 (id·title·posterPath?·voteAverage 10점 …)   [사용 중]
     tmdb_movie_page_dto.dart            페이지 (page·results·totalPages·totalResults)        [사용 중]
     tmdb_genre_dto.dart                 장르 (id·name)                                       [사용 중]
   services/
     tmdb_movie_service.dart             fetchPopular / discoverMovies / fetchGenres          [사용 중]
   storage/
     genre_preference.dart               마지막 선택 장르 id 저장·복원 (null = 전체)           [사용 중]

■ 동작 (Service 한 번 호출)
   _dio.get('/discover/movie', queryParameters: {..., 'with_genres': ?genreId})
     → TMDB 응답 → response.data(Map<String, dynamic>)
     → TmdbMoviePageDto.fromJson → results 각각 TmdbMovieDto.fromJson
   실패는 DioException으로 ViewModel에 전달된다 (Service는 잡지 않는다).

■ 누가 무엇을 쓰나
   fetchPopular      ← MovieHomeViewModel (앞 5개)
   discoverMovies    ← MovieListViewModel (page 1부터 최대 30개, 장르 조건)
   fetchGenres       ← MovieListViewModel (장르 Chip 목록)
   GenrePreference   ← MovieListViewModel (첫 로드 복원, 장르 선택 시 저장)

■ DTO 작성 규칙
   - 숫자는 as num으로 받아 toInt()/toDouble() (JSON 8은 int, 8.4는 double)
   - JSON snake_case(poster_path) → Dart camelCase(posterPath)로 직접 연결
   - null일 때 화면이 달라야 하면 String?(posterPath), 아니면 기본값(title ?? '제목 없음')
   - overview·release_date는 null 대신 ""로 올 수 있다 → 화면에서 isEmpty 확인

■ 의존 관계
   사용   : dio(services), shared_preferences(storage)
   사용처 : app/movie_log_app.dart(Service 생성), router/app_router.dart(GenrePreference 생성),
            view_models/*, widgets/tmdb_*, screens/*(표시용 DTO 타입)

■ 수정할 때 주의
   - Service는 상태를 갖지 않는다(결과를 필드에 저장하지 않음) → 여러 ViewModel이 안전하게 공유.
   - 'with_genres': ?genreId — genreId가 null이면 항목 자체를 넣지 않는다("전체" 조회).
   - GenrePreference Key는 'selected_genre_id'(int). 4주차 'selected_genre'(문자열)는 읽지 않는다.

■ 예정된 변경
   - Challenge 장르 다중 선택: discoverMovies가 여러 id를 '|'로 연결한 with_genres를 받도록 확장
   - 이후: TMDB 상세 API(/movie/{id}) 메서드·DTO 추가 시 상세 화면이 id만으로 표시 가능
