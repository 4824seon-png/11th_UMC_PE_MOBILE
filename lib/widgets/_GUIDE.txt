[폴더] widgets/ — 여러 화면이 함께 쓰는 공통 위젯
════════════════════════════════════════════════════════════════

■ 이 폴더의 역할
   - 두 개 이상의 화면에서 재사용하는 위젯을 둔다.
   - 데이터는 생성자로 받아 그리기만 한다 (ViewModel·Service를 직접 찾지 않음).

■ 넣지 않는 것
   - 한 화면에서만 쓰는 위젯 → screens/<화면>/widgets/

■ 파일 목록
   movielog_app_bar.dart     공용 AppBar (높이 64, actions 선택)                     [사용 중]
   tmdb_poster_image.dart    poster_path → 이미지 URL, null·로드 실패 시 placeholder   [사용 중]
   tmdb_movie_card.dart      TMDB 영화 카드 (포스터·★10점·제목·연도, 탭 → 상세)       [사용 중]
   movie_card.dart           4주차 Mock 영화 카드 (★5점)                              [삭제 예정]

■ 동작
   TmdbPosterImage
     URL = https://image.tmdb.org/t/p + /w500 + posterPath
     posterPath null·"" → 요청 없이 placeholder / 로드 실패 → errorBuilder placeholder
     width·height 생략 시 부모 영역(Positioned.fill, StackFit.expand)을 채운다
   TmdbMovieCard
     크기는 부모가 정한다(홈: SizedBox 150×280, 목록: Grid 칸)
     칸 높이 계산용 TmdbMovieCard.infoHeight = 60
     탭 → context.push('/movies/${movie.id}')

■ 의존 관계
   사용   : data/models/tmdb_movie_dto.dart, go_router
            (movie_card.dart만 data/legacy/movie.dart)
   사용처 : screens/home(tmdb_*), screens/movie_list(movie_card, app_bar), screens/profile(app_bar)

■ 수정할 때 주의
   - 카드 내부의 Expanded가 남은 높이를 포스터에 주므로, 높이가 정해지지 않은 곳에 두면 오류가 난다.
   - 평점은 TMDB vote_average(10점 만점)를 그대로 표시한다.

■ 예정된 변경 (Required Mission)
   - movie_grid가 TmdbMovieCard를 쓰게 되면 movie_card.dart 삭제
   - 상세 화면 포스터에 TmdbPosterImage 재사용 가능
