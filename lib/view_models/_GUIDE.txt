[폴더] view_models/ — 화면별 상태와 로직 (ChangeNotifier)
════════════════════════════════════════════════════════════════

■ 이 폴더의 역할
   - 화면(페이지)마다 ViewModel을 하나씩 둔다.
   - 로드 상태(idle/loading/success/empty/error), 화면에 필요한 데이터, 화면 정책을 가진다.
   - 사용자 입력(재시도·장르 선택)에 따라 Service를 호출하고 notifyListeners()로 알린다.

■ 넣지 않는 것
   - Widget·BuildContext (화면을 그리는 코드)
   - HTTP 요청·JSON 파싱 → data/services/, data/models/

■ 파일 목록
   movie_home_view_model.dart   홈: Popular 앞 5개                              [사용 중]
   movie_list_view_model.dart   영화 탭: 장르 + Discover 최대 30개 + 장르 재조회 [사용 중]

■ MovieHomeViewModel.loadPopular
   loading → notify → fetchPopular() → take(5) → success|empty / error → notify

■ MovieListViewModel
   loadInitial()
     ① _startLoading (버전 발급, loading, notify)
     ② fetchGenres → 저장된 장르 id 복원(목록에 있을 때만) → notify (Chip 먼저 표시)
     ③ _fetchUpToThirtyMovies(복원 장르) → success|empty → notify
   selectGenre(id)        로드 중이면 무시(미션 7), 같은 장르면 무시
                          → 저장(unawaited) → _loadMovies (page 1부터 with_genres 재조회)
   retry()                장르 목록이 없으면 loadInitial, 있으면 현재 장르로 _loadMovies
   _fetchUpToThirtyMovies page 1부터 discoverMovies 반복
                          Map<id, 영화>로 중복 제거, 30개 또는 마지막 페이지(totalPages)에서 종료
                          [영화 목록] N개 (요청 P페이지, 장르: …) 로그
   isLoading              idle|loading — 화면(Chip 비활성)과 VM(변경 거부)이 함께 사용

■ 공통 규칙
   - 값을 바꾼 "뒤에" notifyListeners()를 부른다.
   - Service·저장소는 생성자로 주입받는다 → 테스트에서 가짜로 교체 가능.
   - on DioException 외의 예외(TypeError 등)도 error로 처리 → Loading에 멈추지 않게.
   - await 뒤마다 _isStale(version) 확인: dispose됐거나 더 새 요청이 있으면 결과를 버린다.
   - 상태는 enum + switch로 다룬다 (빠진 상태가 있으면 컴파일 에러).

■ 의존 관계
