[폴더] router/ — URL과 화면 연결, 화면별 ViewModel 생성
════════════════════════════════════════════════════════════════

■ 이 폴더의 역할
   - GoRouter로 모든 경로(URL)와 화면을 한 곳에서 관리한다.
   - 화면 전용 ViewModel을 ChangeNotifierProvider로 해당 Route에서 만든다.

■ 파일 목록
   app_router.dart   AppRouter.router, indexFromLocation()   [사용 중]

■ 경로 표
   /start              StartScreen          탭 없음, 앱 첫 화면
   /register           RegisterScreen       탭 없음
   ── ShellRoute (MainScreen = 하단 탭) ──
   /home               HomeScreen           + MovieHomeViewModel..loadPopular()
   /movies             MovieListScreen      (Required에서 MovieListViewModel 연결)
   /my                 ProfileScreen
   ──
   /movies/:movieId    MovieDetailScreen    탭 없음, TMDB id를 Path Parameter로 받음

■ ViewModel 생성 방식 (/home 예시)
   ChangeNotifierProvider(
     create: (context) => MovieHomeViewModel(context.read<TmdbMovieService>())..loadPopular(),
     child: const HomeScreen(),
   )
   - create는 화면에 처음 들어올 때 1번만 실행 (rebuild마다 재요청하지 않음)
   - ..(캐스케이드): loadPopular()를 호출하고, create의 결과로는 ViewModel 자신을 반환
   - 탭을 떠나면 ViewModel dispose → 다시 오면 새로 만들어 다시 요청 (정상)

■ 의존 관계
   사용   : go_router, provider, screens/*, view_models/*, data/services/tmdb_movie_service.dart
   사용처 : app/movie_log_app.dart (routerConfig)

■ 수정할 때 주의
   - router는 static final (앱 전체에서 1개). build 안에서 만들면 위치가 초기화된다.
   - MainScreen 탭 순서(홈 0, 영화 1, 마이 2)와 indexFromLocation 번호를 맞춘다.

■ 예정된 변경 (Required Mission)
   - /movies: ChangeNotifierProvider<MovieListViewModel>(..loadInitial())로 감싸기
   - /movies/:movieId: TMDB id로 상세 화면이 영화를 표시하도록 보완 (미션 8)
